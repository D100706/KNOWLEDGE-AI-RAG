# 2-minute demo script

1. **Introduction (15 sec):** “This is Knowledge AI, a RAG-based document assistant.”
2. **Upload (20 sec):** Upload `AI_Introduction.txt` and `RAG_Architecture.txt`.
3. **Indexing (20 sec):** Click Process documents. Explain extraction, chunking, embeddings, and FAISS indexing.
4. **Ask (30 sec):** Ask “What are the two main RAG workflows?” Show the answer.
5. **Evidence (20 sec):** Expand retrieved sources and explain source/page/chunk metadata and similarity scores.
6. **Architecture (15 sec):** Briefly show the architecture diagram in README.
7. **Closing (10 sec):** Explain that Groq can synthesize an answer from retrieved context and that the fallback displays retrieved passages.
